# IQ Test Application

## Overview

IQ Test Application is a web-based project that allows users to take an interactive IQ test and receive results based on their answers.

## Purpose

The goal of this project is to simulate a simple online IQ testing system and practice handling user interaction and logic in web applications.

## Features

* Interactive questions
* Answer selection system
* Result calculation
* Simple and clean interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## What I Learned

* Handling user input with JavaScript
* Managing question flow
* Implementing result calculation
* Creating interactive UI
